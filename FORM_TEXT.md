# Demo Day form text

## What do you want to build for your demo day project?

**RoamSafe - a programmable travel wallet on Solana that lets a traveler create a temporary trip vault with an on-chain budget, spending limits, trip dates, an emergency reserve, and an emergency lock/recovery mechanism.**

## Three-sentence blurb

RoamSafe is a temporary, programmable travel wallet that lets users move only their planned travel budget into a Solana-controlled vault and define rules for how that money can be spent. Before every travel payment, the on-chain program checks the trip dates, emergency-lock status, maximum transaction amount, daily spending limit, protected emergency reserve, and available vault balance, rejecting the transaction if any rule is violated. At the end of the trip - or if the wallet is compromised - the owner can lock the trip and recover unused funds back to their main wallet.
